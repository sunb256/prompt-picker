# Agent Prompt Picker v9（AutoHotkey v2）

AHK v2だけで動く、コーディングエージェント向けプロンプト検索・貼り付けツールです。追加ライブラリ不要です。

## v9 の変更

- 検索欄に文字がある場合、`Esc` を押すと検索文字列を消去し、全候補を表示します（ウィンドウは閉じません）。
- 検索欄が空の場合、`Esc` でウィンドウを非表示にします。
- 日本語IME変換中は、これまで通り変換のキャンセルを優先します。
- それ以外のUI、ソート、貼り付け動作はv8と同じです。

## v8 の変更

- YAMLの記述順に関係なく、**Category → Command の昇順**で表示します（英字の大文字・小文字は区別しません）。同じCategory・CommandのときはYAMLの元の順序を維持します。
- 左側ペインを旧版の約**70%**（初期幅470px → 330px）に縮め、右側の詳細プレビューを広げました。Category列は110px → 約78px、Command列は325px → 約222pxです。
- ウィンドウサイズ変更時も左側の比率を約34%に保ちます。リスト列が狭い場合は表示が省略されますが、検索はすべてのフィールドを対象とします。
- YAML形式・ショートカット・自動非表示はv7から変更していません。

## v7 で導入したYAML形式

- YAMLの `label` を `command`（英語の短い名前）に変更しました。
- `details` を追加し、日本語の説明を設定できるようにしました。右ペインの見出しに表示します。
- YAMLの `replace` を `content`（貼り付け本文）に変更しました。
- 左側リストのフォントを 10pt → **9pt** にしました。検索欄・プレビューの文字サイズは維持しています。
- 左リストは **Category | Command** の2列のままです。`details` は右側に表示し、全文検索にも含まれます。
- 旧形式の `label`、`replace`、`trigger` も引き続き読み込めます。ただし、旧形式では英語の `command` がないため、一覧では旧 `label` が代わりに表示されます。

## セットアップ

1. `PromptPicker.ahk` と `prompts.yml` を同じフォルダに置きます。
2. 実行中の旧版を終了し、AutoHotkey **v2** で `PromptPicker.ahk` を起動します。
3. 自分の既存 `prompts.yml` を維持したい場合は、サンプルで上書きせず、次の書式に変更してください。

```yaml
matches:
  - category: "Agent"
    command: "Review Changes"
    details: "変更差分をレビュー"
    content: |
      現在の変更差分をレビューしてください。
      問題点と理由を整理してください。
```

## 操作

| キー | 操作 |
| --- | --- |
| `Ctrl+Alt+P` | 検索を表示・非表示 |
| 文字入力 | Category / Command / Details / Content をインクリメンタルAND検索 |
| `↑/↓`, `Ctrl+K/J` | 候補を移動（検索欄にフォーカスしたまま） |
| `Enter` | 貼り付け（クリップボードを上書き） |
| `Ctrl+Enter` | コピーのみ |
| `Esc` | 検索文字があればクリア、空なら非表示（IME変換中は変換キャンセル） |
| `Ctrl+E` | YAMLをエディタで開く |
| `Ctrl+R` | YAMLを再読み込み |
| `Ctrl+F` | 検索欄にフォーカス |
| GUI外へフォーカス移動 | 自動非表示 |

ダブルクリックでも貼り付けられます。日本語IMEの変換中はIMEのキー操作を優先します。

## YAMLについて

外部パーサーを用いないため、YAMLの**限定的な構文**のみ対応しています。`matches:` の下で2スペースの `-`、4スペースのフィールドキー、6スペース以上の `content: |` 本文を使用してください。標準YAMLのエイリアス、アンカー、折りたたみブロック等には対応しません。

Windowsでの実動作検証は未実施です。ZIP内の構造とコードの静的検査のみ実施しています。
